# 桌面端彩票选号器（lottery-picker）设计文档

日期：2026-08-22
状态：已确认（用户已确认技术方案与功能设计，并补充中奖地址数据要求）

## 1. 项目概述

Windows 桌面端彩票选号器，包含两个功能完全相同但数据相互独立的板块：**双色球** 和 **大乐透**。

每个板块提供：
1. 查看往期 100 期开奖号码
2. 号码分布图（频次 / 遗漏 / 奇偶大小区间占比）
3. 近 100 期最大奖（单注最高奖金 + 个人最高中奖金额）
4. 中奖地址地图（只收录每期最大奖，可缩放，精确到市 + 网点号）
5. AI 选号（本地统计规则引擎，基于往期 100 期号码生成推荐）

## 2. 技术架构

- **框架**：Electron（主进程 + 渲染进程）
- **渲染层**：Vue3 + Vite + ECharts（图表与中国地图）+ Element Plus（UI 组件，可选）
- **数据层**：主进程内置 Node 抓取脚本，对接官方 API；数据缓存于本地 JSON 文件
- **选号引擎**：纯前端本地统计规则，离线可用、零成本、可解释

### 2.1 为什么选 Electron 主进程抓数据

- 官方 API 存在跨域/反爬限制，渲染进程直接请求会被拦截；主进程（Node）请求无跨域问题，最稳定
- 主进程负责数据缓存与更新，渲染进程只做展示，职责清晰

## 4. 数据层设计

### 4.1 数据源

| 数据 | 来源 | 接口/方式 |
|------|------|-----------|
| 双色球开奖号码 + 各等奖金额 | 福彩官网 | `https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice?name=ssq&issueCount=100`（JSON） |
| 大乐透开奖号码 + 各等奖金额 | 体彩官网 | `https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry?gameNo=85&provinceId=0&pageSize=100&isVerify=1&pageNo=1`（JSON） |
| 中奖地址（一等奖站点） | 每期开奖公告详情页 | 从官方公告/详情页抓取一等奖中奖列表：省、市、网点号（精确到市即可） |
| 个人最高中奖金额 | 开奖公告/媒体 | 尽力抓取，缺失标注"未收录" |

### 4.2 中奖地址抓取规则（用户确认）

- 每期一等奖中奖站点：官网开奖公告公布中奖详情，包含**省、市、网点号**（如"广东深圳市 第 83021118 号网点"）
- **只收录每期最大奖**：地图散点 = 每期一等奖中奖站点（每期最大奖）；若当期一等奖有多个站点，全部标出，弹窗标注单注奖金
- **精确到市**：不需要街道/详细站点名；地图按市级坐标落点
- 抓取不到的期数：地图不落点，列表中标注"未收录"

### 4.3 数据缓存与更新

- 缓存路径：`userData/lottery-data/ssq.json`、`dlt.json`
- 应用启动：主进程检查缓存 → 有且 ≥100 期直接使用；不足或过期则调用官方 API 补抓
- 界面提供"刷新数据"按钮，手动触发全量更新
- 缓存结构：
```json
{
  "game": "ssq",
  "updatedAt": "2026-08-22T15:00:00+08:00",
  "draws": [
    {
      "issue": "2024098",
      "date": "2024-08-22",
      "red": [3, 9, 15, 22, 27, 31],
      "blue": 7,
      "firstPrizePerBet": 10000000,
      "firstPrizeCount": 4,
      "maxPersonalWin": 50000000,
      "maxPersonalWinNote": "广东深圳 第xxx号网点 5注",
      "winners": [
        { "province": "广东", "city": "深圳市", "siteNo": "83021118", "amount": 10000000 }
      ]
    }
  ]
}
```

## 5. 界面与功能设计

### 5.1 整体布局

```
┌────────────────────────────────────────────┐
│ 顶部导航：🎯 彩票选号器    [双色球] [大乐透] │
├────────────────────────────────────────────┤
│  [刷新数据]  [数据更新时间]                 │
│ ┌─────────────┬──────────────────────────┐ │
│ │ 功能区 Tab   │ 内容区                   │ │
│ │ 往期号码     │ (按所选 Tab 展示)         │ │
│ │ 分布图       │                          │ │
│ │ 最大奖       │                          │ │
│ │ 中奖地图     │                          │ │
│ │ AI 选号      │                          │ │
│ └─────────────┴──────────────────────────┘ │
└────────────────────────────────────────────┘
```

### 5.2 功能模块

#### 5.2.1 往期号码（HistoryTable）
- 表格：期号、开奖日期、号码（双色球 6红+1蓝 / 大乐透 5前+2后，号码球样式配色）、单注一等奖金额
- 期号搜索框
- 分页或滚动加载（100 条）

#### 5.2.2 分布图（DistributionChart）
- 频次柱状图：每个号码（双色球 01-33、大乐透前区 01-35）近 100 期出现次数，热号红色、冷号蓝色
- 遗漏值折线：各号码当前遗漏（可切换查看）
- 占比环形图：奇偶占比、大小占比、区间分布（大乐透三区 2:2:1、双色球三区 2:2:2 参考线）

#### 5.2.3 最大奖（MaxPrizeCard）
- 卡片 1：近 100 期**单注最高奖金**——期号、开奖日期、金额、当期号码
- 卡片 2：近 100 期**个人最高中奖金额**——金额、期号、城市/网点（尽力抓取，缺失标"未收录"）
- 附：近 100 期一等奖注数 / 单注奖金走势小图（可选）

#### 5.2.4 中奖地址地图（PrizeMap）
- ECharts 中国地图（geo），内置 `china.json` GeoJSON
- 散点 = 每期最大奖（一等奖）中奖站点，**只收录每期最大奖**
- 点的大小/颜色按奖金金额分级（小奖浅色小点、大奖深色大点）
- 点击散点弹出 tooltip：期号、日期、奖金、省、市、网点号
- **支持滚轮缩放、拖拽平移**（`roam: true`）
- 多期同市聚合：同市多个点自动聚集显示数量，点击展开该市各期明细（避免点重叠）
- 无数据期数：不落点，下方列表标注"未收录"

#### 5.2.5 AI 选号（AiPicker）
本地统计规则引擎 `picker-engine.js`，输入近 100 期数据，输出 1 注主推 + 2 注备选，并展示依据：
- 热号加权：近 10 期出现 ≥3 次的热号提高权重
- 冷号回补：遗漏 ≥10 期的冷号保留少量权重（不超 1 个/注）
- 区间均衡：大乐透 2:2:1、双色球 2:2:2（±1 容错）
- 奇偶均衡：3:2/2:3（大乐透）、3:3（双色球）
- 和值区间：大乐透 90~110、双色球 85~120
- 连号限量：至多 1 组二连号
- 每注输出各维度命中情况（得分条）
- "换一组"按钮重新生成

## 6. 主进程 IPC 接口

| 通道 | 方向 | 说明 |
|------|------|------|
| `data:get` | 渲染→主 | 获取某游戏数据（ssq/dlt），主进程返回缓存或触发抓取 |
| `data:refresh` | 渲染→主 | 手动刷新数据，主进程重新抓取并返回 |
| `data:status` | 渲染→主 | 查询数据状态（更新时间、期数、缺失情况） |

## 7. 错误处理

| 场景 | 处理 |
|------|------|
| 官方 API 请求失败 | 使用本地缓存，界面提示"数据更新失败，展示上次缓存（日期）" |
| 首次使用无缓存且抓取失败 | 显示重试引导，不崩溃 |
| 中奖地址抓取缺失 | 地图不落点，列表标"未收录"，不影响其他功能 |
| 接口结构变化 | 抓取脚本做字段容错，解析失败的单期跳过并记录日志 |
| 网络超时 | 主进程设置超时（默认 15s），失败快速返回可重试 |

## 10. 风险与边界

- 官方 API 可能调整或增加反爬：数据更新功能设计为可降级（用缓存），不阻塞核心功能
- 中奖地址历史公告页结构可能随版本变化：抓取器集中在一个模块，便于维护
- 大乐透/双色球头奖概率极低：应用内置理性购彩提示（固定预算提醒）
